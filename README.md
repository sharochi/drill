## 公開版を編集するときの注意

### `DATA` 配列の最終要素には末尾カンマがない

`];` の直前の行は `}` で終わっています。問題を追記するときは、**既存の最終要素にカンマを補ってから**足すこと。そのまま足すとJS構文エラーになり、サイトが真っ白になります。

### 科目・分野の追加にコード変更は不要

```js
const SUBJ = [...new Set(DATA.map(d=>d.s))];
```

科目チップは `DATA` から動的に生成され、総問題数も `DATA.length` から出ます。`s` と `c` を増やすだけでUIに反映されます。

### 更新のたびに直すもの

- `<meta name="description">` の科目名
- フッターの「◯年◯月時点の条文にもとづく」

### 問題文はHTMLとして解釈されない

描画はすべて `textContent`。`<` や `&` が入っても安全ですが、タグを書いてもそのまま文字として表示されます。

### 同じURLに上書きする

学習履歴（`localStorage`）はオリジンごとに保存されます。公開URLを変えると、利用者の「あやふや」リストがすべて消えます。

## CSVパイプライン（②）を使うときの手順

```bash

python3 validate_questions.py questions.csv

```

### 問題IDは変えない

IDは学習履歴のキーです。**一度公開したIDは変更・再利用しない。** 削除する場合も欠番にします。

- `LB-001`〜`LB-062` 労働基準法
- `KY-001`〜`KY-101` 雇用保険法
- `AE-001`〜`AE-056` 労働安全衛生法
- `RS-001`〜`RS-016` 労災保険法
- `CS-001`〜`CS-015` 労働保険徴収法
- 新科目は `KN-`（健保）、`KO-`（厚年）、`KM-`（国年）、`IP-`（一般常識）を予定

旧バージョンは配列インデックス（`q0`, `q1`, …）をIDにしていたため、問題を挿入すると学習履歴がずれるバグがありました。`id_map.json` による一度きりの移行で解消済みです。

## 条文照合の手順

e-Gov 法令検索のAPIをブラウザから直接叩くのが速い。

```
/api/1/lawdata/<法令ID>   → XML。Article要素の Num属性で条番号を引く
```

| 法令 | 法令ID |
|---|---|
| 労働基準法 | `322AC0000000049` |
| 健康保険法 | `211AC0000000070` |
| 健康保険法施行令 | `215IO0000000243` |
| 健康保険法施行規則 | `215M10000008036` |

- 枝番の条は `43_2` の形式
- **`SupplProvision`（附則）配下の Article も同じ Num を持つため、除外しないと本則の条文が上書きされます**
- 法令一覧は `/api/1/lawlists/2`（政令）`/3`（勅令等）`/4`（府省令）から法令名で引ける

### 健保の検証で出た誤りの型（他科目でも起きうる）

- **その数字が本当にその条文にあるか**。一部負担金の「義務教育就学前2割」は法74条になく、被扶養者の家族療養費（法110条）の給付割合8割だった
- **期限が別の法律にあることがある**。審査請求3か月・再審査請求2か月は健保法ではなく社会保険審査官及び社会保険審査会法
- **本則か附則か**。国庫補助の1000分の164は法153条ではなく法附則5条の「当分の間」の読み替え
- **条文か通達か**。随時改定の「2等級以上」「固定的賃金の変動」はいずれも条文になく通達
