# 社労士 数字ドリル

社会保険労務士試験に出てくる**数字要件**だけを、自己採点でひたすら回すための学習ツールです。

**→ https://sharochi.github.io/drill/**

無料・登録不要。ブラウザだけで動きます。

## 収録

**全520問／8科目**

| 科目 | 問数 |
|---|---|
| 労働基準法 | 62 |
| 労働安全衛生法 | 64 |
| 労災保険法 | 44 |
| 雇用保険法 | 71 |
| 労働保険徴収法 | 24 |
| 健康保険法 | 92 |
| 国民年金法 | 82 |
| 厚生年金保険法 | 81 |

すべての問題に根拠条文を付けています。数字と条文は e-Gov 法令検索の条文本文と突合済みです。

年金2法（国民年金法・厚生年金保険法）は、**2025年（令和7年）年金制度改正法による改正後の、令和8年10月1日施行の条文**にもとづいています。第1号被保険者の育児期間に係る保険料免除など、施行済みの改正を反映しています。

## 使い方

問題を見て頭の中で答え、スペースキーで解答を表示。「わかった」「あやふや」の2択で自己採点します。

- **あやふや**にした問題は5問後に自動で再出題されます
- 苦手な問題はブラウザに記録され、次回「あやふやだった問題のみ」で絞り込めます
- 科目 → 分野の2階層で出題範囲を指定できます
- キーボードだけで操作できます（スペースで解答表示、1・2で自己採点）
- ダークモード対応。スマートフォンではホーム画面に追加すればアプリのように使えます

## 数字の基準日について

条文は**2026年10月時点**のものにもとづいています。

年金額・保険料額・在職老齢年金の支給停止調整額など、**年度ごとに改定される数字**も収録していますが、その問題には「毎年度改定される」旨を補足に明記しています。年度が替わったら、そこだけ読み替えてください。

法律の本則と政令で額が違う論点（厚生年金の標準報酬月額の最高等級、在職老齢年金の支給停止調整額など）は、**どちらを聞いているかを問題文で明示**しています。
