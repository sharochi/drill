# 労基法 数字ドリル

社会保険労務士試験の受験生向けに、**労働基準法の「数字要件」だけを高速で反復する**ための学習ツールです。

「6時間を超える場合は45分」「平均賃金の1200日分」のように、条文の中でも数字は最後まで曖昧になりやすく、かつ本試験で最も点差がつく部分です。そこだけを切り出して、繰り返し当てられるようにしました。

**▶ [ここで使う](https://USERNAME.github.io/roukihou-drill/)**

---

## 特徴

- **62問** を9分野に分類（労働時間／割増賃金／年次有給休暇／賃金／解雇・退職／労働契約／年少者・妊産婦／就業規則・記録／災害補償）
- **自己採点式** — 問題 → 答えを見る → 「わかった／あやふや」で仕分け
- **あやふやは自動で再出題** — 5問後にもう一度出るので、全部「わかった」になるまで終わらない
- **苦手を記憶** — 端末に保存され、次回「あやふやだった問題のみ」で再開できる
- **分野の絞り込み**とシャッフルに対応
- **キーボード操作** — スペースで解答表示、`1`／`2` で自己採点
- ダークモード対応。スマホのホーム画面に追加すればアプリのように使えます
