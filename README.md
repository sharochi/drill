# 社労士 数字ドリル

社会保険労務士試験の受験生向けに、**条文の「数字要件」だけを高速で反復する**ための学習ツールです。

「6時間を超える場合は45分」「遺族補償一時金は1000日分」「延納の第2期は10月31日」——条文の中でも数字は最後まで曖昧になりやすく、かつ本試験で最も点差がつく部分です。そこだけを切り出して、繰り返し当てられるようにしました。

**▶ [ここで使う](https://sharochi.github.io/drill/)**

---

## 収録内容

**全265問／労働科目5法**

| 科目 | 問数 | 分野 |
|---|---|---|
| 労働基準法 | 62 | 労働時間／割増賃金／年次有給休暇／賃金／解雇・退職／労働契約／年少者・妊産婦／就業規則・記録／災害補償 |
| 労働安全衛生法 | 64 | 管理体制／作業環境・機械等／健康診断／面接指導・ストレスチェック／安全衛生教育／届出・報告／記録の保存 |
| 労災保険法 | 44 | 適用・特別加入／給付基礎日額／療養・休業／傷病・障害／遺族・葬祭／認定基準／その他の給付／時効・手続 |
| 雇用保険法 | 71 | 適用・被保険者／基本手当／算定基礎期間／所定給付日数／傷病手当・延長給付／日雇労働／就職促進給付／教育訓練給付／雇用継続給付／育児関係給付／時効・不正 |
| 労働保険徴収法 | 24 | 保険関係・届出／延納／印紙保険料／メリット制／追徴金・延滞金／事務組合 |

科目と分野を自由に組み合わせて、出題範囲を絞れます。

2025年4月施行の改正（自己都合退職の給付制限の短縮、高年齢雇用継続給付の給付率引下げ、出生後休業支援給付金・育児時短就業給付金の創設、就業促進定着手当の上限率変更）にも対応しています。

全問について、e-Gov法令検索の条文本文および厚生労働省の公表資料と突き合わせる校閲を行い、さらに直近8〜10年の本試験の出題実績と照合して、頻出論点の抜けを補っています。「被保険者期間」と「算定基礎期間」の区別のように、本試験で狙われる用語の差も答えに反映しました。

## 特徴

- **自己採点式** — 問題 → 答えを見る → 「わかった／あやふや」で仕分け
- **あやふやは自動で再出題** — 5問後にもう一度出るので、全部「わかった」になるまで終わらない
- **苦手を記憶** — 端末に保存され、次回「あやふやだった問題のみ」で再開できる
- **科目・分野の絞り込み**とシャッフルに対応
- **条文の参照つき** — 答えと一緒に根拠条文が出るので、そのまま六法に戻れる
- **キーボード操作** — スペースで解答表示、`1`／`2` で自己採点
- ダークモード対応。スマホのホーム画面に追加すればアプリのように使えます
